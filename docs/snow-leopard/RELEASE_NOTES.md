# 雪豹闭嘴 0.1.0-alpha01

非商业、非官方衍生版。基于 SleepDown课程表 修改；原作者 xiaomanjun233；原项目 https://github.com/xiaomanjun233/SleepDown-Schedule 。完整源码与构建脚本：https://github.com/W-Boat/shutup 。保留原许可及第三方声明。

- 新增声音保护首页、六种固定模板和自定义模板。
- 支持全天、固定时段、跨午夜、有效日期及课表绑定；冲突采用更严格策略。
- 新增可调媒体上限、暂停、自动纠正音量、可信耳机、临时放行与状态恢复。
- 保留课表导入到日周展示；覆盖导入前生成可恢复快照。
- 接入用户自填 AI API，规则先预览确认；增加权限检查与本地记录。
- 可选 Shizuku 增强接口；无法确认路由时继续限制媒体。
- 仅通过 GitHub Actions 构建、测试与打包。

限制：不承诺绝对零漏音或系统硬锁；蓝牙路由、播放器、系统后台与耗电须完成真机验收。签名版需配置自有签名 Secrets。
